# Inventario completo de funciones y callbacks

Este índice se obtuvo del árbol sintáctico del código JavaScript/JSX propio. Incluye funciones nombradas, métodos de clases, funciones internas y callbacks anónimos. Una etiqueta de callback sirve para localizarlo: no es un nombre añadido a la aplicación. Las llamadas son referencias estáticas directas; no prueban ejecución dinámica ni sustituyen la explicación funcional del documento enlazado.

Los scripts de instalación sin funciones propias ejecutan código de nivel superior y se explican en [Operación](operacion.md). Las seis funciones SQL se explican en [Base de datos](base-de-datos.md). No se indexan funciones de dependencias, snippets de documentación ni código compilado.
